# ALGO-NAFIS-LENS

An interactive web app that visualizes classic DSA interview patterns step-by-step, with live execution logs and time/space complexity breakdowns.

## 🎯 What it does
ALGO-NAFIS-LENS turns abstract algorithm patterns into animated, step-by-step visualizations. Instead of just reading how an algorithm works, you can watch pointers move, values compare, and windows slide in real time — with a live log tracking every operation as it happens.

## 🛠️ Built with
- HTML
- CSS
- JavaScript

## 🧩 Patterns covered
- ✅ Reverse String (two-pointer)
- 🔜 Two Sum (brute force vs. hashmap)
- 🔜 Sliding Window
- 🔜 Binary Search
- 🔜 Bubble Sort

## 💡 What I learned
Building the animation logic taught me how to break an algorithm down into discrete, visualizable steps rather than just implementing it to return a final answer — which forced a much deeper understanding of what each pointer/comparison is actually doing at every stage.
